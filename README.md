# 🎵 Spotify Clone

A Spotify-inspired desktop music streaming interface built using **HTML5 and CSS3**. This project recreates the visual layout of Spotify's desktop application as a frontend development learning project.

## 📸 Project Preview

*Screenshots coming soon!*

## ✨ Features

- Spotify-inspired top navigation bar
- Home button and search bar
- Install App and profile section
- Library sidebar
- Playlist, Artists, and Albums categories
- Custom playlist and artist sections
- Hover effects on interactive-looking elements
- Dark-themed user interface

## 🛠️ Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling, Flexbox, spacing, and hover effects
- **Font Awesome 6** – Icons

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Manishamehal12/Spotify-clone.git
   ```

2. Open the project folder:

   ```bash
   cd Spotify-clone
   ```

3. Open `index.html` in your browser or use the Live Server extension in VS Code.
